# 닷츠 보이스

닷츠와 ChatGPT의 답변을 낭독하고 닷츠 통화의 목소리를 바꾸는 비공식 Windows 앱입니다. 한국어 목소리는 원문을 읽고, 일본어 목소리는 일본어로 번역해 읽습니다.

## 다운로드

[Releases](https://github.com/tuna-dots/dots-voice-release/releases)에서 `DotsVoice-Windows-Share.zip`을 받으세요. ZIP에는 일본어 160개와 한국어 150개 보이스 팩, 이미지 사용법 5장이 들어 있습니다. 포함된 목소리는 Steam 설치 없이 사용할 수 있습니다.

## 처음 실행하기

1. Windows 11에서 ZIP을 모두 풀고 `DotsVoice/DotsVoice.exe`를 실행합니다.
2. **계정 및 번역**에 본인의 Fish Audio API 키를 입력합니다. 일본어 번역을 사용할 경우 ChatGPT 또는 Gemini API도 연결합니다.
3. **목소리**와 **오디오 장치**를 고른 뒤 **저장 및 적용**을 누릅니다.
4. **시험 재생 → 샘플 재생**으로 확인합니다. 자세한 안내는 압축을 푼 폴더의 `DotsVoice/이미지 사용법`에 있습니다.

## 주요 기능

- 닷츠, 일반 ChatGPT, 워크, 코덱스 답변의 자동 낭독을 각각 켜고 끌 수 있습니다.
- 용도, 프로젝트, 대화별로 목소리를 지정할 수 있습니다.
- Windows 알림 권한을 설정하면 닫힌 닷츠 대화 알림과 코덱스 행동 허가 요청도 읽을 수 있습니다.
- 앱 상단과 Windows 트레이에서 낭독을 중지할 수 있습니다.

## 계정과 음성 합성

키와 로그인 정보는 각 사용자의 Windows 프로필에 저장됩니다. 읽을 텍스트와 음성 참조 샘플은 합성을 위해 Fish Audio로 전송됩니다. 일본어 번역을 사용할 때는 원문이 선택한 번역 서비스로 전송됩니다.

캐릭터와 원음의 출처는 블루 아카이브와 해당 ASMR 작품입니다. 이 앱은 넥슨의 공식 앱이 아닙니다.
